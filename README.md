# AI Chat Overlay 2.0

AI Chat Overlay 2.0 — это легковесный, полупрозрачный AI-чат, который всегда находится поверх всех окон. Он создан для того, чтобы помочь вам оставаться в «потоке», не переключаясь на браузер для взаимодействия с нейросетями.

## Основные возможности

*   **Мгновенный доступ**: Открывайте чат по горячей клавише прямо поверх вашей IDE, редактора или браузера.
*   **Мультимодальность**: Поддержка скриншотов — просто выделите область, и AI проанализирует её.
*   **Агностичность**: Вы сами выбираете модель. Поддерживаются Gemini, OpenAI, Anthropic, DeepSeek и любые кастомные API-эндпоинты.
*   **Локальное хранение**: Вся история чатов и настройки хранятся локально в базе данных SQLite.
*   **Безопасность**: API-ключи шифруются с использованием системных средств защиты (на основе `safeStorage`).

## Установка

1.  Убедитесь, что у вас установлен [Node.js](https://nodejs.org/).
2.  Клонируйте репозиторий: `git clone <ваш-репозиторий>`
3.  Установите зависимости: `npm install`
4.  Запустите приложение: `npm start`

## Сборка для себя

Для сборки исполняемого файла используйте команду:
`npm run build`
