# AI Chat Overlay Beta

AI Chat Overlay Beta — это легковесный, полупрозрачный AI-чат, который всегда находится поверх всех окон. Он создан для того, чтобы помочь вам оставаться в «потоке», не переключаясь на браузер для взаимодействия с нейросетями.

## Основные возможности

*   **Мгновенный доступ**: Открывайте чат по горячей клавише прямо поверх вашей IDE, редактора или браузера.
*   **Мультимодальность**: Поддержка скриншотов — просто выделите область, и AI проанализирует её.
*   **Агностичность**: Вы сами выбираете модель. Поддерживаются Gemini, OpenAI, Anthropic, DeepSeek и любые кастомные API-эндпоинты.
*   **Локальное хранение**: Вся история чатов и настройки хранятся локально в базе данных SQLite.
*   **Безопасность**: API-ключи шифруются с использованием системных средств защиты (на основе `safeStorage`).

## Установка

Приложение не требует установки Node.js или других зависимостей. Просто скачайте готовый файл:

1.  Зайдите в папку `dist` (или скачайте из релизов).
2.  Используйте установочный файл (`.exe`) или портативную версию для запуска без установки.
